한 번 연결하면, 이후에는 시트의 자료만 수정하세요.

배포 파일 내려받기 ↓전체 설치 안내

Google 계정과 GitHub 계정이 필요합니다. 설치는 PC에서 진행해 주세요.

자료는 각자 관리
다른 선생님의 수정과 섞이지 않아요.

학생은 로그인 없이
완성된 사이트 주소만 공유하세요.

수업 주제는 자유롭게
기사·보고서·SNS 글을 함께 탐색해요.

01

내 자료 시트 만들기

새 Google 스프레드시트를 만듭니다. 확장 프로그램 → Apps Script를 열고 기존 코드를 지운 뒤 아래 파일의 전체 내용을 붙여 넣으세요.

Apps Script 코드 내려받기 ↓

저장하고 함수 목록에서 setupArticlesSheet를 선택해 한 번 실행합니다. 생성된 articles 탭에 자료를 입력하고 published를 체크하세요. 날짜 설정은 시트와 스크립트 모두 서울로 맞춥니다.

연결 확인용 첫 자료를 입력하려면

2행의 A열 id에 test-001, B열 title에 ‘연결 확인’, D열 content에 ‘내 시트의 자료입니다.’를 입력하고 L열 published를 체크합니다. 나중에 사이트에서 ‘연결 확인’을 검색한 뒤 이 행을 삭제하세요.

02

내 시트를 검색 사이트에 연결하기

Apps Script에서 배포 → 새 배포 → 웹 앱을 선택합니다. 실행 사용자는 나, 액세스 권한은 모든 사용자로 설정하고 승인합니다. 발급된 /exec 주소를 아래에 붙여 넣으세요.

학교 계정에서 ‘모든 사용자’를 선택할 수 없다면 관리자에게 Apps Script 익명 웹 앱 허용 여부를 확인해야 합니다. 로그인 화면이 나오는 주소는 학생 사이트에서 사용할 수 없습니다.

입력한 주소는 이 페이지에서 서버로 전송하거나 저장하지 않습니다. 주소 형식만 확인하며, 실제 연결 성공 여부를 판정하지 않습니다.

1번 버튼에서 받은 ZIP의 압축을 풉니다. 방금 만든 config.js로 폴더 안의 docs/config.js를 교체하세요. 파일명이 config (1).js라면 config.js로 바꿉니다.

03

내 검색 사이트 공개하기

  1. GitHub에서 새 저장소를 만듭니다. 이름은 class-search, 공개 범위는 Public으로 지정하세요.
  2. 저장소의 ‘uploading an existing file’ 또는 Add file → Upload files를 누릅니다.
  3. 압축을 푼 namsan-starter 폴더 안의 내용물을 업로드하고 Commit changes를 누릅니다. ZIP 자체를 올리지 않습니다. 최상위에 docs 폴더가 보여야 합니다.
  4. Settings → Pages → Deploy from a branch에서 main /docs를 선택하고 Save를 누릅니다.

배포가 끝나면 Pages에 표시된 사이트 주소를 여세요. 일반적으로 https://계정명.github.io/class-search/ 형식입니다.

04

확인하고 학생에게 공유하기

시크릿 창에서 사이트를 열고 ‘연결 확인’을 검색합니다. 글을 누르면 내 시트에 쓴 본문이 보여야 합니다. 시트의 본문을 바꾼 뒤 약 3분 후 사이트를 새로고침해 수정 내용도 확인하세요.

이제 기사·보고서 등 수업 자료를 추가하세요. tags와 keywords에 환경오염,공기오염,미세먼지처럼 관련 검색어를 쉼표로 넣을 수 있습니다.

학생에게는 사이트 주소만 공유합니다. 자료 시트는 선생님이 관리하고, 학생에게 정답·신뢰도 판정을 표시하지 않습니다.

사용 전에 알아두세요

기존 NAMSAN 자료도 복사되나요?

이 배포 파일은 빈 자료 목록으로 시작합니다. 원래 운영자의 시트·API 연결·250건의 기사와 교사용 분류는 포함하지 않습니다. 선생님이 직접 검토한 자료를 자기 시트에 넣어 운영합니다.

자료를 바꿀 때마다 다시 배포하나요?

아니요. 시트의 행만 수정하면 됩니다. 최대 약 3분 뒤 사이트를 새로고침하면 반영됩니다. API 주소나 사이트 코드, Apps Script 코드를 바꿀 때에는 해당 설정 또는 배포를 갱신해야 합니다.

처음에 자료가 안 나오거나 연결에 실패하면?

아직 연결하지 않은 빈 템플릿에는 검색 결과가 없습니다. API를 연결했는데 오류가 나면 웹 앱의 익명 접근 권한, /exec 주소, articles 탭 이름, 헤더, 중복 id를 확인하세요. 배포본은 오류 시 다른 사람의 자료로 대신하지 않도록 fallback을 꺼 두었습니다.

공개 범위는 어떻게 되나요?

이 사이트는 준비한 자료 안에서만 검색하지만 인터넷 주소를 아는 누구나 공개된 글을 읽을 수 있습니다. 원본 시트는 비공개로 두고 학생 이름 등 개인정보를 넣지 마세요. 교사용 분류·난이도·추가 관리 열은 API 응답에서 제외됩니다. 자료와 이미지에는 출처와 이용 조건을 확인하세요.
